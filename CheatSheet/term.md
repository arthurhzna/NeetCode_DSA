## Lexicographically

**Lexicographically** means ordering items the same way words are ordered in a dictionary.

In this order, elements are compared from left to right character by character.

Example:
"apple" < "banana" < "cat"

Another example:
"app" < "apple"

# Programming Terms

## Distinct Array
A **distinct array** is an array where all elements are unique, meaning no duplicate values exist.

Example:
[1, 2, 3, 4]  -> distinct  
[1, 2, 2, 3]  -> not distinct
## Substring

A **substring** is a contiguous sequence of characters within a string.

Example:
String: "hello"

Substrings:
"he"
"ell"
"hello"
"lo"

Note:
A substring must appear continuously in the original string.

## Palindrome

A **palindrome** is a string that reads the same forward and backward.

Example:
"ana"
"racecar"
"level"

Explanation:
"ana" reversed is still "ana".
